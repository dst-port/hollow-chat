# HollowChat — Project Plan

## Общее
- Домен: hollowchat.app
- Концепция: приватный мессенджер для геймеров, альтернатива Discord
- Подписка: Hollow Chatter
- Лицензия: AGPLv3 — open source, форкнул и закрыл = обязан открыть исходники
- Репозиторий: GitHub
- Позиция: законопослушный сервис, GDPR compliant, но технически дать властям нечего
- Код открыт — юзеры могут сами проверить отсутствие бэкдоров и телеметрии

## Стек

| Компонент | Технология |
|---|---|

| Frontend | Svelte 5 + TypeScript |

| База данных | PostgreSQL |

## Аутентификация

- Юзер вводит только username при регистрации
- Сервер генерит криптографически случайный пароль (24+ символа)
- Показываем пароль юзеру ОДИН РАЗ с большим предупреждением "СОХРАНИ ЭТО"
- Кнопка "я сохранил" — только после неё пускаем дальше
- На сервере хранится только Argon2id хэш + pepper
- Pepper хранится в .env, НИКОГДА в БД
- Потерял пароль = потерял аккаунт, юзер предупреждён
- Никакой почты, никакого телефона
- QR логин с уже залогиненного устройства (версия 2.0)
- QR токен привязывается к публичному ключу устройства (генерится при первом логине, хранится локально зашифрованно) — НЕ к browser fingerprint, он слабый в Tauri webview

---

## Что хранится в БД

```
users:
  - id
  - username
  - password_hash (Argon2id)
  - created_at

messages:
  - id
  - encrypted_blob (сервер не может читать)
  - timestamp
  - channel_id
  (НЕТ: sender_id если Sealed Sender, НЕТ: IP)
```

Больше ничего личного. Хакер получает БД — видит username и хэш, делает ничего.

## Приватность и анонимность

### Zero Log Policy
- Nginx/Caddy — логи полностью отключены
- Axum — никаких access логов, только критические ошибки без IP
- PostgreSQL — audit logging отключён
- Coturn — логи отключены
- Cloudflare — минимальный retention

### Два режима подключения

**Default:**
```
Юзер → Cloudflare → Сервер
```
- Cloudflare скрывает реальный IP сервера
- сервер не логирует CF-Connecting-IP

**Paranoid (Tor):**
```
Юзер → Tor (arti встроен) → Сервер
```
- один тоггл в настройках
- в Tor режиме голосовые звонки АВТОМАТИЧЕСКИ отключаются
- предупреждение о латентности

## Шифрование

### Сообщения
- Signal Protocol через libsignal (официальная либа Signal Foundation)
- libsignal лицензия AGPLv3 — совместима, т.к. весь HollowChat тоже AGPLv3 (см. раздел "Общее")
- Sealed Sender — сервер не видит кто кому пишет
- Perfect Forward Secrecy встроен в Signal Protocol
- Device verification / safety numbers для юзеров
- Сервер видит только зашифрованные блобы

### Файлы
- каждый файл шифруется отдельным эфемерным ключом
- метадата стрипается на сервере до доставки получателю

### Голос
- SRTP + DTLS
- только через Coturn relay, НИКОГДА P2P
- временные TURN credentials привязанные к сессии (не к аккаунту)
- сервер не может расшифровать звонок
- ОГРАНИЧЕНИЕ АНОНИМНОСТИ: Coturn relay по природе своей видит IP обеих сторон звонка — это архитектурное ограничение UDP/TURN, логи выключены но факт остаётся
- Честно писать в Privacy Policy: голосовые звонки менее анонимны чем текстовые сообщения
- В Tor режиме голос АВТОМАТИЧЕСКИ отключён именно по этой причине
- Coturn стоит за отдельным VPS без Cloudflare (UDP не проксируется через CF)
